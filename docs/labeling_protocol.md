# 电缆缺陷标注及复核规则

本规则用于后续数据质量复核，不会自动更改已有标签。用户确认的实例粒度为：**每条可以清晰区分的划痕单独标注**；多条互相独立的划痕不能仅因距离近而合并成一个大框。

## 操作原则

1. 对一条可辨认的连续划痕，框住该条缺陷的可见范围；不要任意切成多个框。同一处存在多条可区分划痕时分别框出，允许合理重叠。
2. 裂口、孔洞和划痕的类别以项目确认的物理定义为准；类别不清楚、损伤互相遮挡或无法判断实例数的样例标记为待人工复核，不由模型置信度决定。
3. 矩形框应尽量贴近可见缺陷，尤其是长而斜的划痕；矩形框包含背景是轴对齐标注的局限，不应把模型预测轮廓误认为真值。
4. 同一图中所有可见缺陷按同一规则检查完整性，不能只标容易识别的目标；空标签要区分真实无缺陷和尚未完成标注。
5. 模型预测与标注不一致、预测未匹配或标注未检出只构成**复核候选**。人工确认后再保存新版本，并保留原版本和修改记录；不得将模型输出直接作为独立金标。

## 论文评测隔离

- 不根据当前模型的得分在验证集上逐轮改标签或挑选样例。规则确定后应由未参与模型调参的标注者统一复核、记录版本并冻结评价集；此前基于旧标签的试验要与新版本明确区分。
- 先按物理电缆段、采集批次及拍摄条件划分，再导出图片、切片及训练清单；没有真实分组记录时只能称近似分组，不能宣称物理独立。
- 最终测试集不得用于训练、伪标签生成、参数搜索或人工依据模型预测定向修改；每个类别和无缺陷样例需要足够数量。
- 如需发布数据或样例，应取得对应授权。仓库默认不包含图片、标签、原始路径、检查点或错误复核截图。
