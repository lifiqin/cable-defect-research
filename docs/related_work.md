## 当前网络假设

细长缺陷和背景纹理都可能形成方向性边缘。单纯加强所有强方向边缘可能同时放大电缆纹路、接缝或高光。实验原型比较两种路由：

1. `tensor`：根据局部结构张量的双角方向分量，融合四个方向深度卷积分支。
2. `contrast`：在相同分支上，使用局部结构分量与较大邻域结构分量的差异进行路由。
3. `hybrid`：结合方形卷积与局部方向路由；`p3p4` 进一步在两个特征尺度插入同类模块。这是对已有方法的组合试验，不预设有论文级原创性。
4. 可选 [SE 风格通道门控](https://arxiv.org/abs/1709.01507)：用于测试几何路由与通道重标定是否互补；SE 本身已有广泛先例。

二者都使用残差旁路，不直接抹除原始特征。该假设有明确风险：真实划痕也可能与背景方向一致，背景中的局部纹理变化也可能触发强响应。需要按这两种场景分别做错误分析，不能只看总 mAP。

## 执行顺序

- 先在完全一致的组划分、标签、超参数与计算预算下，运行 `baseline`、`isotropic`、`uniform`、`tensor`、`contrast` 和 `hybrid`；将 P3 与 P3/P4 位置组合分开考察。模型参数量并非严格匹配；解释结果时需报告参数量和延迟。
- 模型选择只能使用开发集；跨组近重复与标签质量未确认时，结果仅作探索。复核标签后，应使用多个种子、多个电缆段及独立锁定测试集重新运行。
- 再与 YOLO26、RF-DETR 等强基线比较，注明预训练来源和输入尺寸差异。同一评估集上的结果才可直接比较；跨论文、跨数据划分的分数不可直接声称 SOTA。
- 如果结构差异模块未稳定胜过无门控方向对照、对同向细划痕出现漏检，或显著增加延迟，就应调整或放弃该假设，而不是以测试集反复选参。
