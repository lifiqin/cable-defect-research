## 模块组合需要怎样验证

1. **多尺度与浅层细节**：可比较多尺度检测头、较大输入、特征金字塔或裁块推理；不同分辨率和算力预算应单独报告。公开工作已有 [EfficientDet/BiFPN](https://arxiv.org/abs/1911.09070) 等方法，不能将其视为原创。
2. **方向与形状信息**：细划痕可能受益于方向性分支，但背景纹理也有方向。当前原型比较无门控、局部张量路由和局部—邻域结构差异；方向卷积本身已有[相关工作](https://www.mdpi.com/2076-3417/16/22/11181)。
3. **通道与空间注意力**：当前提供 SE 风格通道门控作为可选因子；也可对照 [Dynamic Head](https://arxiv.org/abs/2106.08322) 等方法。组合提升必须与单模块及额外参数量对照。
4. **训练与标注策略**：长时间训练、合理增强和独立标注核查可能比改网络更重要。任何借助图片相似性或模型生成的标签应记录来源，不能当成独立测试金标。

建议采用小规模预先登记的因素实验，而非在测试集上无限排列组合：先做单因素与合理组合，在开发集选择；最后只在独立测试集评估固定方案。若组合的收益不能复现或弱于简单对照，应保留负结果并调整假设。
